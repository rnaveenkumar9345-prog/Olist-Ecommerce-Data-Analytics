# Olist E-Commerce Data Analytics

## Project Overview

An end-to-end E-Commerce Data Analytics project based on the Brazilian E-Commerce Public Dataset by Olist.

The project focuses on analyzing sales performance, customer behavior, product categories, delivery performance, payment methods, customer satisfaction, and freight-cost burden using Python, SQL, and Power BI.

The objective is to transform raw transactional data into meaningful business insights that can support data-driven decision-making.

---

## Business Objective

The main objective of this project is to understand:

- Sales performance and monthly sales trends
- Customer purchasing behavior
- Top-performing product categories
- State-wise sales performance
- Delivery and delay performance
- Payment method usage
- Customer satisfaction
- Freight-cost burden across categories
- Potential business improvement opportunities

## Dataset

**Dataset:** Brazilian E-Commerce Public Dataset by Olist

The dataset contains approximately 100K orders from the Brazilian e-commerce marketplace and includes information related to:

- Customers
- Orders
- Order Items
- Products
- Payments
- Reviews
- Sellers
- Geolocation

The original dataset is not included in this repository.
