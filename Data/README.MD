# Dataset

This project uses the **Brazilian E-Commerce Public Dataset by Olist**, a publicly available e-commerce dataset containing information about orders, customers, products, payments, reviews, sellers, and delivery.

## Data Source

The original dataset is available on Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Dataset Contents

The original dataset contains 9 CSV files:

- Customers
- Orders
- Order Items
- Order Payments
- Order Reviews
- Products
- Sellers
- Geolocation
- Product Category Translation

## Data Used in This Project

The analysis primarily uses:

- Customer data
- Order data
- Order item data
- Product data
- Payment data
- Review data

These datasets were cleaned, transformed, integrated, and analyzed using Python, SQL, and Power BI.

## Data Processing

The data analysis workflow included:

- Data cleaning
- Missing-value handling
- Duplicate checking
- Data type conversion
- Date/time transformation
- Dataset integration
- Feature engineering
- Exploratory Data Analysis (EDA)
- Business-focused analysis

## Important Note

The original Olist dataset is **not included in this repository** because it is publicly available through Kaggle and the raw dataset is not required to reproduce the repository structure.

Please download the original dataset directly from the source above.

## Data Limitation

The dataset does not contain actual product cost/COGS information. Therefore, this project does not calculate actual business profit.

Instead, freight cost and freight burden were analyzed as indicators for potential cost-optimization opportunities.
